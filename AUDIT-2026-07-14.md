# Full-Repo Audit — 2026-07-14

Four parallel audits (backend bugs, frontend bugs, responsiveness, UX flows) + live mobile browser sweep of all public routes. Findings verified against code; the top checkout finding confirmed by direct read.

**Excluded by design:** the 4 open findings in `backend/.claude/memory/SECURITY.md` (F1–F4, awaiting QA sign-off) are not repeated here.

---

## P0 — Broken money paths (fix before anything else)

| # | Finding | Where | Impact |
|---|---------|-------|--------|
| 1 | **Card checkout is broken end-to-end.** `emptyCart()` runs in Step 1 (after order creation, before Stripe confirm). Emptying the cart re-renders the page into the `items.length === 0` empty-cart screen, unmounting `CardElement` mid-payment → `elements.getElement(CardElement)` is null → payment can never complete. User is left with an unpaid pending order and an empty cart; the retry hint is unreachable. | `frontend/src/Pages/CartCheckoutPage/CartCheckOutPage.jsx:146,153,185` | Every Stripe checkout fails |
| 2 | **PayPal charges MUR amounts as USD.** Every `currencyCode` in the PayPal service is hardcoded `'USD'` with `value: order.finalAmount` (rupees). Rs 3,000 order → $3,000 charge (~×40 overcharge). Stripe path correctly uses `'mur'`. | `backend/src/services/paypal.service.js:39,43,47,55,119` | Massive overcharge on any PayPal payment/refund |
| 3 | **Subscription created before payment succeeds** (and errors swallowed): declined card still leaves an active recurring subscription. | `frontend/.../CartCheckOutPage.jsx:135-143` | Recurring orders for never-paid purchases |
| 4 | **Refund modal is fake.** `handleSubmit` = `setTimeout(900)` + success toast ("our team will contact you within 24-48h"); no API call, nothing recorded. | `frontend/src/Pages/MyOrders/MyOrdersPage.jsx:108-116` | Trust breach; legitimate return requests silently lost |
